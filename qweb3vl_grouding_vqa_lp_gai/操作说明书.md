# Qwen3-VL 视觉定位grouding SFT 语料生成接口操作说明书

## 1. 项目背景

本项目用于将目标检测标注数据转换为 Qwen3-VL 可用于监督微调的视觉定位 SFT 语料。原始标注数据不是标准 LabelMe 格式，而是采用如下结构：

```json
{
  "id": "00001",
  "image": "00100.jpg",
  "image_width": 1000,
  "image_height": 500,
  "shapes": [
    {
      "label": "track",
      "points": {"x": 169, "width": 68, "y": 181, "height": 63}
    }
  ]
}
```

其中 `points` 表示像素坐标下的目标框，字段含义为左上角坐标 `x、y` 和框宽高 `width、height`。项目会将该格式转换为 Qwen3-VL 视觉定位常用的 `bbox_2d` 输出格式，默认坐标范围为 `0~1000`。

项目目标是实现标准化、可复用的视觉定位语料生成能力，并通过 FastAPI 对外提供接口服务。

## 2. 项目内容

本项目主要包含以下能力：

1. 解析非 LabelMe 的 `x/y/width/height` 标注格式。
2. 将像素框 `[x, y, width, height]` 转换为 `[x1, y1, x2, y2]`。
3. 将像素坐标映射到 Qwen3-VL `0~1000` 相对坐标系。
4. 根据配置生成不同类型的视觉定位 SFT 样本。
5. 输出 ShareGPT/Qwen 多模态对话格式数据。
6. 通过 FastAPI 提供单条标注转换接口。

## 4. 输入数据格式

接口请求体只接收 `annotation` 字段，不再接收 `config` 和 `image_path`。配置统一从 `config.py` 中读取，图片路径统一从 `annotation.image` 中读取。

标准输入格式如下：

```json
{
  "annotation": {
    "id": "00001",
    "image": "00100.jpg",
    "image_width": 1000,
    "image_height": 500,
    "shapes": [
      {
        "label": "track",
        "points": {"x": 169, "width": 68, "y": 181, "height": 63}
      }
    ]
  }
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `annotation` | object | 是 | 单条图片标注数据。 |
| `annotation.id` | string | 建议填写 | 样本 ID，会用于生成输出样本 ID。 |
| `annotation.image` | string | 是 | 图片路径或图片文件名。 |
| `annotation.image_width` | integer | 是 | 图片宽度，单位为像素。 |
| `annotation.image_height` | integer | 是 | 图片高度，单位为像素。 |
| `annotation.shapes` | array | 是 | 标注框数组。 |
| `shapes[].label` | string | 是 | 目标类别名称。 |
| `shapes[].points.x` | number | 是 | 标注框左上角 x 坐标。 |
| `shapes[].points.y` | number | 是 | 标注框左上角 y 坐标。 |
| `shapes[].points.width` | number | 是 | 标注框宽度。 |
| `shapes[].points.height` | number | 是 | 标注框高度。 |

Windows 绝对路径建议使用双反斜杠或正斜杠：

```json
"image": "E:\\航天\\视觉定位语料生成\\labelme_samples\\00000100.jpg"
```

或：

```json
"image": "E:/航天/视觉定位语料生成/labelme_samples/00000100.jpg"
```

## 5. 坐标转换规则

原始标注框格式为：

```text
x, y, width, height
```

第一步转换为像素框：

```text
x1 = x
y1 = y
x2 = x + width
y2 = y + height
```

第二步转换为 Qwen3-VL `0~1000` 坐标：

```text
qwen_x1 = round(x1 / image_width * 1000)
qwen_y1 = round(y1 / image_height * 1000)
qwen_x2 = round(x2 / image_width * 1000)
qwen_y2 = round(y2 / image_height * 1000)
```

示例：

```json
{
  "image_width": 640,
  "image_height": 480,
  "points": {"x": 64, "width": 512, "y": 48, "height": 384}
}
```

像素框：

```json
[64, 48, 576, 432]
```

Qwen3-VL 坐标：

```json
[100, 100, 900, 900]
```

## 6. 参数说明

配置文件为 `grouding_vqa/config.py`。

### 6.1 基础参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `DEFAULT_BBOX_SCALE` | `1000` | bbox 坐标归一化尺度。 |
| `DEFAULT_COORDINATE_MODE` | `qwen_relative_1000` | 坐标转换模式。 |
| `DEFAULT_DATASET_FORMAT` | `sharegpt` | 输出数据格式。 |
| `DEFAULT_TASK_TYPES` | 以 `config.py` 实际配置为准 | 默认生成的任务类型。 |

### 6.2 `DEFAULT_CONFIG` 参数

| 参数 | 说明 |
| --- | --- |
| `annotation_dir` | 批量处理时的标注目录。 |
| `output_jsonl` | 批量处理输出 JSONL 文件路径。 |
| `image_dir` | 批量处理时的图片根目录。 |
| `annotation_glob` | 标注文件匹配规则，例如 `*.json`。 |
| `recursive` | 是否递归扫描标注目录。 |
| `generation.coordinate_mode` | 坐标模式，支持 `qwen_relative_1000` 和 `pixel`。 |
| `generation.bbox_scale` | 坐标归一化尺度，默认 `1000`。 |
| `generation.dataset_format` | 输出格式，当前主要使用 `sharegpt`。 |
| `generation.output_image_path` | 输出图片路径形式，支持 `filename`、`absolute`、`relative`。 |
| `generation.task_types` | 生成任务类型列表。 |
| `generation.include_metadata` | 是否在样本中包含元信息。 |
| `generation.ignore_labels` | 需要忽略的标签列表。 |
| `generation.min_box_size` | 最小有效框尺寸，小于该值的框会被过滤。 |

### 6.3 任务类型说明

`generation.task_types` 支持以下取值：

| 任务类型 | 说明 | 输出特点 |
| --- | --- | --- |
| `detect_all` | 定位图中所有已标注目标。 | 输出 JSON 数组。 |
| `detect_label` | 按类别定位目标。 | 每个类别生成一条样本，输出 JSON 数组。 |
| `ground_single` | 单目标指代定位。 | 每个目标生成一条样本，输出 JSON 对象。 |
| `vlm_grounding_qa` | 综合定位问答任务。 | 生成全目标、类别目标、单目标等多类问答。 |

例如设置为：

```python
DEFAULT_TASK_TYPES = ["detect_all"]
```

则接口每次只生成一条“检测全部目标”的 SFT 样本。

例如设置为：

```python
DEFAULT_TASK_TYPES = ["ground_single"]
```

则每个标注框生成一条单目标定位样本。

## 7. 输出数据格式

接口成功返回格式如下：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "stats": {
      "annotations": 1,
      "boxes": 1,
      "samples": 1
    },
    "samples": [
      {
        "id": "00001_detect_all",
        "images": ["00100.jpg"],
        "conversations": [
          {
            "from": "human",
            "value": "<image>\n请定位图中所有已标注目标，输出JSON数组，每个元素包含bbox_2d和label。"
          },
          {
            "from": "gpt",
            "value": "[{\"bbox_2d\":[100,100,900,900],\"label\":\"track\"}]"
          }
        ],
        "metadata": {
          "source_annotation": "00001",
          "source_image": "00100.jpg",
          "image_width": 640,
          "image_height": 480,
          "coordinate_mode": "qwen_relative_1000",
          "bbox_scale": 1000,
          "task_type": "detect_all"
        }
      }
    ]
  }
}
```

输出字段说明：

| 字段 | 说明 |
| --- | --- |
| `code` | 接口业务状态码，`0` 表示成功。 |
| `message` | 接口返回信息。 |
| `data.stats.annotations` | 处理的标注数量。 |
| `data.stats.boxes` | 有效标注框数量。 |
| `data.stats.samples` | 生成的 SFT 样本数量。 |
| `data.samples` | 生成的 SFT 样本列表。 |
| `samples[].images` | ShareGPT 多模态图片字段。 |
| `samples[].conversations` | 多轮对话数据。 |
| `metadata` | 样本来源、图片尺寸、坐标模式、任务类型等元信息。 |

## 12. 常见问题

### 12.1 接口返回 `name 'config_override' is not defined`

原因是旧版本代码中残留了已删除的 `config_override` 参数引用。当前版本已修复，接口只读取 `config.py` 中的默认配置。若服务已启动，请重启 Uvicorn 服务。

### 12.2 Windows 路径导致 JSON 解析失败

JSON 字符串中的反斜杠需要转义。推荐使用：

```json
"image": "E:\\航天\\视觉定位语料生成\\labelme_samples\\00000100.jpg"
```

或：

```json
"image": "E:/航天/视觉定位语料生成/labelme_samples/00000100.jpg"
```

### 12.3 生成样本数量与预期不一致

请检查 `config.py` 中的 `DEFAULT_TASK_TYPES`：

```python
DEFAULT_TASK_TYPES = ["detect_all"]
```

不同任务类型会生成不同数量的样本：

| 配置 | 样本数量规则 |
| --- | --- |
| `["detect_all"]` | 每张图生成 1 条。 |
| `["detect_label"]` | 每个类别生成 1 条。 |
| `["ground_single"]` | 每个标注框生成 1 条。 |
| `["vlm_grounding_qa"]` | 根据 `qa_per_image_min` 和 `qa_per_image_max` 生成多条。 |

### 12.4 bbox 坐标看起来不是像素坐标

默认 `coordinate_mode` 为 `qwen_relative_1000`，输出是映射到 `0~1000` 的相对坐标。如果需要输出原始像素坐标，可在 `config.py` 中设置：

```python
DEFAULT_COORDINATE_MODE = "pixel"
```

并同步确认 `DEFAULT_CONFIG["generation"]["coordinate_mode"]` 使用该值。

## 13. 注意事项

1. 输入框宽高必须大于 0。
2. `image_width` 和 `image_height` 必须准确，否则 Qwen3-VL 坐标转换会不准确。
3. 标签为空的标注框会被过滤。
4. 标签在 `ignore_labels` 中的标注框会被过滤。
5. 修改 `config.py` 后，需要重启 FastAPI 服务才能生效。
6. 接口当前只处理单条 `annotation`，批量转换请使用脚本入口。
