**从下面这几个维度换着变**，这是花样的来源，不要靠加语气词凑：

- 换动词：定位 / 框出 / 标出 / 输出 / 找出 / 给出 / 圈出 / 指出 / 描述 / 说明
- 换要什么：位置 / 坐标 / 边界框 / 检测框 / 框
- 换句式：祈使句（「框出图中的X。」）和疑问句（「X在图中的什么位置？」）都要有
- 换语序：「图中的X在哪个位置」/「X位于图中的什么位置」
- 换详略：带不带「图中」「画面里」「请」，句子有长有短

**不要出现的东西**（下面这些全是反面例子）：

    诶那辆卡车在哪儿？          语气词
    帮我把图里的人员框出来       客套、代人做事的口气
    话说那辆三轮车在哪块儿呢     闲聊腔、儿化音
    麻烦看得清的都有什么         客服话术
    这玩意儿是啥                 俚语

不带语气词、不带口头语、不带客套、不带儿化音。
