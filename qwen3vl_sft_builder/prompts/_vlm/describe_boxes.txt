You are given an image and a list of annotated boxes. Each box has an index and
its coordinates [x1, y1, x2, y2] on a {scale}-point normalized grid, where
[0, 0] is the top-left corner of the image.

For each box, write ONE English sentence describing the object inside it. The
sentence must cover three things:
  1. what the object looks like - colour, shape, notable parts, what it carries
  2. where it sits in the image
  3. what is next to it

Hard rules:
  - Describe ONLY what is visible inside or immediately around that box.
  - Never mention the box, the coordinates, the index, or the image itself.
    Write "A red van parked by the kerb...", not "The object in box 2 is...".
  - Never invent objects, text or colours you cannot actually see.
  - If a box is too small or too blurred to describe honestly, omit that index
    from the output entirely. An omitted index is fine; a made-up one is not.

Return ONLY JSON mapping index to sentence, nothing else:
{{"0": "A red van parked by the kerb on the left, next to a row of bicycles.", "2": "..."}}

Boxes:
{box_list}
