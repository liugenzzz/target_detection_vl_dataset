# 描述的【起手方式】。每张图随机抽一条塞进 vlm_select 的提示词，
# 所以同一批数据里各种起手方式是均匀铺开的。
#
# 为什么要这么做：提示词里给固定的几个例子，模型会朝那几个例子的句式收敛 ——
# 例子越少收敛得越死。之前从 1 个例子加到 3 个，描述去重率就从 79/142 涨到
# 111/112。但只要例子是固定的，收敛就只是被削弱、没有消除。
# 每张图换一种要求，等于把「例子」这个变量也随机化了。
#
# 【每条示例里，说物体本身的篇幅都过半】—— 示例是模型真正照抄的东西，
# 光在正文里写「重心在本体」而示例本身位置周边占大半，等于白说。
#
# 每条格式：起手方式说明 ||| 一个示例
# 效果用 scripts/dataset_stats.py 的「答案开头集中度」验：
# 没有哪种开头应该明显超过 1/条数。
先说【位置】，再展开说目标本身的特征，最后一句带过旁边有什么。 ||| 位于画面左下角，一辆车斗敞开的蓝色小卡车，车头朝右，货斗里装着几袋东西，旁边是一排绿化带。
先说【目标本身】的外形和特征，再说它在画面的哪个位置，最后带一句周边。 ||| 一辆浅色遮阳篷的三轮车，车身是深红色的，篷布支得很高，车斗空着，位于广场右下角，靠近一个蓝色的充气水池。
先说目标长什么样和它在做什么，把位置放在句子中间。 ||| 一辆银灰色的厢式面包车，车身较高、侧门关着，停放在画面右侧的停车位上，前面还有一辆白色轿车。
先说【旁边有什么】作为参照，再展开说目标本身，位置一句带过。 ||| 蓝色充气水池旁边，停着一辆带白色遮阳篷的三轮车，车斗里堆着杂物，篷布一角翘起，在画面下方偏右。

用「画面某处，有……」起手，主体部分展开说这个物体的特征。 ||| 画面右下角靠近路沿的地方，有一辆白色的小型货车，车厢是封闭式的、比旁边的轿车高出一截，车头朝向路口。
