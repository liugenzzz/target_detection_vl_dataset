# 描述的【起手方式】。每张图随机抽一条塞进 vlm_select 的提示词，
# 所以同一批数据里各种起手方式是均匀铺开的。
#
# 为什么要这么做：提示词里给固定的几个例子，模型会朝那几个例子的句式收敛 ——
# 例子越少收敛得越死。之前从 1 个例子加到 3 个，描述去重率就从 79/142 涨到
# 111/112。但只要例子是固定的，收敛就只是被削弱、没有消除。
# 每张图换一种要求，等于把「例子」这个变量也随机化了。
#
# 每条格式：起手方式说明 ||| 一个示例
# 效果用 scripts/dataset_stats.py 的「答案开头集中度」验：
# 没有哪种开头应该明显超过 1/条数。
先说【位置】，再说目标长什么样，最后说旁边有什么。 ||| 位于画面左下角，一辆带有遮阳篷的三轮车停在步道旁，周围有几个人聚集。
先说【目标本身】长什么样，再说它在画面的哪个位置，最后说旁边有什么。 ||| 一辆浅色遮阳篷的三轮车，位于广场右下角，靠近一个蓝色的充气水池。
先说目标长什么样和它在做什么，把位置放在句子中间。 ||| 一辆银灰色的面包车停放在广场边缘的停车位上，位于画面右侧，旁边有一辆白色轿车。
先说【旁边有什么】作为参照，再说目标本身和它的位置。 ||| 蓝色充气水池旁边，停着一辆带遮阳篷的三轮车，在画面下方偏右。
从目标的【颜色或材质】起手，然后说位置和周边。 ||| 深蓝色车身的卡车，停在画面正中偏上的路口处，前方是一条斑马线。
从目标【正在做的动作或状态】起手，然后说位置和周边。 ||| 正沿路面行驶的一辆摩托车，位于画面右上角，紧邻一排店铺门脸。
用「画面/图中的某某位置，有……」这种句式起手。 ||| 画面右下角靠近路沿的地方，有一辆白色的小型货车，车旁站着两个人。
